# My Travel Blog

## Description
This repository hosts the code for a simple, static travel blog website. It showcases travel experiences, destinations, and photos using HTML and CSS.

## Live Demo
Explore the travel blog deployed via GitHub Pages here:
[https://guyltech.github.io/My-Travel-Blog/](https://guyltech.github.io/My-Travel-Blog/)

## Features
* Displays travel blog entries or articles.
* Includes descriptions and images related to various travels.
* Structured using HTML and styled with CSS.
* Simple navigation between pages or sections (if applicable).

* HTML5
* CSS3

## How to View Locally
1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/guyltech/My-Travel-Blog.git](https://github.com/guyltech/My-Travel-Blog.git)
    ```

2.  **Navigate into the directory:**
    ```bash
    cd My-Travel-Blog
    ```

3.  **Open the `index.html` file** (or your main blog homepage HTML file) in your preferred web browser.
